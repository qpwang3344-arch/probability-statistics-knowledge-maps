# 数理统计知识图谱

本仓库汇集数理统计课程的知识图谱、经典阅读、前沿文献与课程思政教学资源，可用于课堂教学、课前导学和学生自主复习。

## 在线内容

- 数理统计课程地位知识图谱
- 第五章：统计量及其分布
- 第六章：点估计
- 第六章：区间估计
- 第七章：假设检验
- 第八章：方差分析与线性回归
- 概率统计课程思政元素图谱
- 数理统计课程经典阅读文献
- 数理统计前沿与应用文献

## 使用方法

打开 GitHub Pages 首页后，通过首页卡片进入各个专题页面。所有页面均为独立静态 HTML，不需要安装软件或构建依赖。

网站地址：<https://qpwang3344-arch.github.io/probability-statistics-knowledge-maps/>

每个专题页面都有独立网址和专属二维码。二维码 PNG 文件集中保存在 `qrcodes/`，可下载后用于 PPT、雨课堂或纸质教学材料。
